# Submission checklist

Include / share this repository (or a zip of it) with:

- [x] Source code (`app/`)
- [x] README.md
- [x] Database migrations (`alembic/`)
- [x] API docs (FastAPI `/docs` + `docs/postman_collection.json`)
- [x] Automated tests (`tests/`, run with `pytest -q`)
- [x] `.env.example`
- [x] Docker Compose (`docker-compose.yml`)

Do not submit `.env`, `.venv/`, or local cache folders.
